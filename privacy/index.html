Privacy policy

Last updated: 11 November 2026

This policy covers rclone-notes, a private file-sync tool operated by a single individual for their own use. It is not a public service and does not create accounts for anyone else.

1. What information is accessed

When you authorise the tool with your Google Account, it requests the Google Drive scope. It uses that permission to list, download, and upload files within one folder of the authorising user's own Google Drive. No other Google data — no email, contacts, calendar, or profile information — is requested or accessed.

2. How information is used

Accessed files are copied between the user's own computer and the user's own Google Drive. They are used for no other purpose.

3. Storage and retention

An OAuth authorisation token is stored on the operator's own computer, in a file readable only by that user. Copies of files exist only on that computer and in the user's Google Drive. No copy is retained anywhere else.

4. Sharing and disclosure

No data is sold, rented, shared, or disclosed to any third party. There is no analytics, telemetry, advertising, or tracking of any kind. The tool communicates directly with Google's API endpoints and with no other server.

5. Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, which immediately stops all access. Deleting the local token file has the same effect.

7. Changes

Any change to this policy will be published on this page with an updated date.
